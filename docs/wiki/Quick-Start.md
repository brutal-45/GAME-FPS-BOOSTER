# ⚡ Quick Start

Everything you need to go from zero to boosted FPS in under a minute.

---

## 1. Install the app

Pick your platform and follow [Installation](Installation):

- **Windows** — `BRUTAL-FPS-Setup-1.0.1.exe`
- **macOS** — `BRUTAL-FPS-1.0.1-x64.dmg` / `-arm64.dmg`
- **Linux / Kali** — `BRUTAL-FPS-1.0.1.deb`, `.AppImage`, or the Kali package

## 2. Launch it

| Platform | How |
|----------|-----|
| Windows | Start Menu / desktop shortcut |
| macOS | Applications folder |
| Linux | `brutal-fps` (deb) or run the AppImage |

The **BRUTAL-FPS dashboard** opens with a sidebar of 9 sections.

## 3. Run your first boost

1. Click **⚡ BRUTAL BOOST** in the sidebar
2. Choose a mode (Balanced is safe for everyday gaming)
3. Press the big **💀 BRUTAL BOOST 💀** button
4. Watch the progress bar — your profile is applied in seconds

You'll see the FPS gain estimate update on the Dashboard, and an achievement may unlock.

## 🧭 Dashboard tour

| Section | What it does |
|---------|--------------|
| 📊 **Dashboard** | Live FPS/CPU/GPU/RAM/temp, quick actions, boost status |
| ⚡ **BRUTAL BOOST** | Pick a mode and apply the full tuning profile |
| 🎮 **Games** | Search, optimize or add game profiles |
| 📱 **Emulators** | One-click optimization for BlueStacks, LDPlayer, Nox… |
| 🖥️ **Processes** | Set process priorities (Real-time → Low), close tasks |
| 🔧 **System Tweaks** | Power plan, Game Mode, DVR off, latency tweaks, … |
| 🛠️ **Hardware Info** | Auto-detected system specs + recommended settings |
| 🏆 **Achievements** | Earn badges for boosting, tweaks, games, emulators |
| ⚙️ **Settings** | Themes (4), language, startup, overlay, notifications |

## 🗔 System tray

BRUTAL-FPS stays running in the tray:

- **🎮 Open Dashboard** — bring the app back
- **⚡ Quick Boost** — instant boost with your selected mode
- **❌ Quit** — exit the app

## 🧹 Recommended first run

1. Open **System Tweaks** → click **✅ Apply All**
2. Open **Games** → **🎯 Optimize** your main games
3. Open **Emulators** → optimize the emulator you use
4. Back to **BRUTAL BOOST** → pick your mode → 💀 **GO**
